1. ## Objetivo do projeto

Desenvolver uma página web utilizando HTML, CSS e JavaScript, tendo como referência visual um protótipo previamente desenvolvido no Figma.

As ferramentas de Inteligência Artificial foram utilizadas como apoio durante o desenvolvimento, auxiliando na construção, correção e otimização do código. As decisões finais, os testes e a validação do resultado foram feitos pela equipe.

2. ## Ferramentas utilizadas

ChatGPT: auxílio na estruturação, explicação e correção de códigos.
Gemini: criação das imagens utilizadas no site.
VS Code: editor de código utilizado no desenvolvimento.
GitHub: controle de versão e armazenamento do projeto.
Figma: referência visual para a implementação da página.

Ferramenta: ChatGPT

Objetivo: analisar o protótipo e identificar os elementos e as tags necessários para desenvolver a página.

Prompt utilizado:

Analise o protótipo criado no Figma e, após a análise, me dê as tags necessárias para a estruturação da página.

Resultado obtido:

A IA apresentou as tags iniciais necessárias para começar a estruturar a página em HTML. Ela também analisou todo o protótipo e orientou o passo a passo a seguir no desenvolvimento.

3. 2. ## Desenvolvimento da estrutura HTML

Ferramenta: ChatGPT

Objetivo: revisar, corrigir e compreender a estrutura HTML criada pela equipe.

Prompt utilizado:

Chat, agora que temos a estrutura HTML completa e organizada, vou te enviar o código final para que você faça uma revisão completa.

Quero que você:

Analise e revise o código: verifique toda a estrutura HTML e procure possíveis erros de sintaxe, organização, hierarquia, posicionamento e estrutura das tags.
Corrija os erros encontrados: depois da análise, envie o código completo, corrigido e organizado, mantendo a estrutura e a proposta original do projeto.
Explique os erros: apresente uma lista com todos os problemas encontrados, explicando o que estava errado, por que era um erro e como foi corrigido.
Explique o código completo: após a revisão, crie uma lista explicando cada parte do documento HTML, incluindo todas as tags utilizadas, suas funções e a importância de cada uma na estruturação da página.

Quero entender não apenas o que foi corrigido, mas também como funciona cada elemento do código, para que eu possa aprender e melhorar minhas habilidades em HTML. Por favor, faça uma análise detalhada e didática, explicando tudo de forma clara e organizada.

Resultado obtido:

O primeiro código foi escrito pela própria equipe, recorrendo à IA sempre que surgia alguma dúvida ou dificuldade. Depois de finalizado, foi criado um prompt (organizado com a ajuda da IA) pedindo a revisão e a correção do código, a indicação dos erros encontrados e a explicação de cada alteração. Também foi solicitada a explicação de todas as tags HTML utilizadas, para compreender a função de cada uma e como elas contribuem para a estrutura da página.

3. 3. ## Desenvolvimento da estilização CSS

Ferramenta: ChatGPT

Objetivo: implementar o visual do protótipo do Figma e tornar a página responsiva.

Prompt utilizado:

Estilização CSS baseada no protótipo do Figma

Com base no protótipo desenvolvido no Figma, realize a estilização completa da página utilizando CSS, buscando reproduzir o mais fielmente possível o design apresentado.

1. ## Fidelidade ao protótipo

Analise cuidadosamente o protótipo do Figma antes de começar a implementação.
Reproduza com a maior fidelidade possível o layout, as cores, as fontes, os tamanhos, os espaçamentos, os alinhamentos, as imagens, os botões e os demais elementos visuais.
Respeite a identidade visual e a organização dos elementos apresentados no Figma.
Não invente elementos nem altere o design original sem necessidade.
Caso algum detalhe do protótipo não esteja claro, explique a dúvida antes de tomar decisões que possam comprometer a fidelidade visual.

2. ## Responsividade

O site deverá ser totalmente responsivo e oferecer uma boa experiência de navegação em desktop (computadores e notebooks), Android (smartphones e tablets) e iOS (iPhones e iPads). Utilize boas práticas de CSS responsivo, como media queries (@media), Flexbox e CSS Grid quando apropriado, unidades flexíveis (%, rem, vw, vh), imagens adaptáveis e ajustes de espaçamento, tamanho de fontes e organização dos elementos conforme a tela. A página não deve apresentar elementos cortados, sobrepostos, desalinhados ou barras de rolagem horizontais indesejadas.

3. ## Organização e qualidade do código

Mantenha o código limpo, organizado e fácil de entender.
Utilize nomes de classes claros e padronizados.
Organize o CSS por seções, seguindo a estrutura dos elementos da página.
Evite repetições desnecessárias e regras conflitantes.
Utilize comentários para identificar as principais seções e explicar regras importantes.
Preserve a estrutura HTML existente sempre que possível, alterando-a somente quando for realmente necessário para alcançar o resultado do Figma.
Não remova elementos ou funcionalidades já existentes sem justificar a necessidade.

4. ## Comentários e identificação das alterações

Toda alteração realizada deverá ser identificada e explicada por meio de comentários objetivos, sem excessos que dificultem a leitura. Comente as novas regras e os principais blocos de CSS, explique a finalidade de eventuais alterações no HTML e informe quais partes do código foram modificadas e por quê. O objetivo é permitir que outra pessoa consiga entender o código, localizar as alterações e realizar futuras modificações com facilidade.

5. ## Testes e validação

Após finalizar a implementação, verifique se a página está visualmente próxima do protótipo, teste-a em diferentes tamanhos de tela (desktop, Android e iOS), corrija problemas de alinhamento, espaçamento, dimensionamento e posicionamento e confira se imagens, fontes, botões e links continuam funcionando. Não considere o trabalho concluído antes de verificar os principais pontos da página.

6. ## Entrega final

Ao terminar, disponibilize os arquivos do projeto atualizados, o CSS completo, organizado e comentado, e o HTML atualizado, caso tenha sido necessário modificá-lo.

Importante: não substitua todo o código existente sem necessidade. Trabalhe a partir da estrutura atual do projeto, preserve o que já funciona e faça alterações incrementais. Priorize a fidelidade ao Figma, a responsividade, a organização e a facilidade de manutenção do código.

Resultado obtido:

A IA entregou a estilização completa, semelhante ao protótipo do Figma, incluindo toda a parte responsiva do site. Com isso, a página funciona corretamente em dispositivos diferentes, mantendo a experiência do usuário (UX) e a interface (UI).
